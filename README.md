# Event Management Database

Academic project developed during the **Database II** course as part of my Software Engineering studies.

The project implements an **event management system** focused on practicing database operations and CRUD functionality.

## 📚 Project Overview

The system was designed to manage information related to events and their participants.

The application provides CRUD operations for managing:

* Events
* Presentation topics
* Speakers
* Users

The project was developed to practice database modeling, data persistence, and application-level database operations.

## ⚙️ Features

The system supports the fundamental CRUD operations:

* **Create** new records
* **Read** stored information
* **Update** existing records
* **Delete** records

These operations are applied to the main entities of the event management system.
